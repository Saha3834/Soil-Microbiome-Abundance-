
# Dataset Access

This repository does not include the processed SoilMind dataset.

The main notebook expects the following file:

`SoilMind_v3_with_coordinates_and_nasa.csv`

The dataset is available upon reasonable request for academic and reproducibility purposes.

To request access, please contact the project authors and include:

1. Name and institution
2. Purpose of use
3. Intended use of the dataset
4. Whether the request is for reproduction, teaching, or further research

Original data sources include NEON data products and NASA POWER climate data. Users may also reconstruct the dataset using the source data and methodology described in the repository.
